Besoin d'aide ?

voici les règlements à suivre pour jouer à ce jeu

  1. Nom des joueurs :
    • Remplir le nom du prémier joueure
    • Remplir le nom du deuxième joueure
  2. Choisit un bouton pour commencer :
    • Seul le prémière joueur qui choisie le bouton
    • Le bouton que tu choisie va s'affichent dans la case lorsque tu cliques
  3. Commencer :
    • Bouton pour commencer
    • Ton nom et le nom de ton adversaire s'affiche au-dessous
    • Tu peux commencer
  4. Recommencer :
    • Pour recommencer
    • Fait vider tous les champs
